About Project

Project Title

Smart Blood Donor & Emergency Healthcare Assistance System

Project Description

This project helps patients find blood donors and available hospital beds during emergencies. It provides a centralized platform connecting donors, hospitals, blood banks, and patients.

Objectives

  • Blood donor management
  • Emergency blood requests
  • Hospital bed tracking
  • Healthcare accessibility
  • Faster emergency response

Technology Stack
