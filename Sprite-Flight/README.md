# Sprite-Flight

A 2D flight game developed by Nisarg Chauhan

A 2D flight game built with Unity and C#

## Features
- Smooth flight controls
- Obstacle Avoidance
- Score tracking
- Arcade-style gameplay

## Built with
- Unity
- C#

## How to run
1. Clone the repository
2. Open the Project in Unity Hub
3. Open the Main scene
4. Press Play
